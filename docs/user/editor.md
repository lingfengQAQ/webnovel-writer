# 新编辑器：改稿、批注、采纳与保存

适用于 Scriptor **8.2.0**、DSH **0.2.0-rc.2**。截图使用隔离环境中的合成作品和固定响应，未调用收费模型；示例建议用于说明操作，不代表模型改写质量。

## 1. 打开正确的文件

先回到这本书的主对话，再在“书房”逐级展开目录，点击草稿、契约或资料。文档进入宿主标签页；先核对文件名和路径，尤其注意 `稿1.md`、`稿2.md` 等版本。

可编辑文件打开后即可在正文中修改。8.2.0 已替换旧教程的“阅读 / 编辑 / 改动”三模式，Markdown 标题等格式就地预览，frontmatter 元数据由保存器维护。

定稿、冻结内容或其他受保护文件会显示只读原因。它们可阅读、复制、引用和发起审读，不能通过排版、粘贴或改写操作绕过保护；定稿修改仍走原更正流程。

## 2. 选区和右键菜单

![新编辑器右键菜单](images/editor-8.2/menu.png)

选中文字后出现浮动操作栏；右键或“更多”打开完整菜单。菜单上方说明当前选区或段落范围，并显示全文计数；悬停按钮可查看名称与快捷键。

| 操作 | 用途 |
| --- | --- |
| 润色 | 保留事件与人物立场，调整表达 |
| 扩写 | 补充选定部分的描写或展开；应明确内容边界 |
| 精简 | 压缩重复表达，结果需核对 |
| 从这里续写 | 在当前插入位置提出后文候选 |
| 按我的要求改… | 说明具体要求，例如“保留对话，只压缩重复心理解释” |
| 审读 | 对原文提出批注，先保持文字不变 |
| 引用到对话 | 把原文和来源放入输入框，核对后自行发送 |

有选区时操作选区，没有选区时菜单会标明“当前段落”。请求发送给当前主 Agent，沿用所配置模型，可能产生费用。局部编辑请求不会授权自动推进下一章或改写其他章节。

## 3. 提交要求和取消等待

选定正文后按 **Ctrl+K**，或选择“按我的要求改…”，输入要求并按 Enter／发送按钮。续写也可从光标附近的星形入口发起，说明后文方向。

发送后原文附近显示等待或处理状态；主 Agent 忙碌时可能先排队。同范围已有请求时不要重复提交，可点“取消这次请求”，随后修改要求再试。取消后迟到结果不会重新成为该请求的可采纳建议。它不等于中断主 Agent 的所有工作；停止整段对话任务仍使用宿主停止操作。

## 4. 核对行内建议，再决定是否采纳

![行内改写候选](images/editor-8.2/suggestion.png)

结果显示在原文附近，可**采纳、拒绝、换一版、在对话中查看**。聚焦当前建议时 **Tab** 采纳、**Esc** 拒绝，**Alt+] / Alt+[** 切换相邻建议。

续写先以灰字显示。等待期间若你改动了相关原文，编辑器会要求再次核对块状差异，或使失去有效位置的续写作废；先比较再决定，保护自己的新文字。

**采纳只修改编辑缓冲区，还需保存。** Ctrl+Z 可撤销采纳，重做可恢复，最终以保存内容为准。关闭整个宿主会丢失尚未完成的编辑器请求，重启后如有需要重新发起。

## 5. 阅读审读批注

![原文上的审读批注](images/editor-8.2/comment.png)

点击原文旁的批注标记展开意见。可按批注请求修改、带着原文和批注去对话讨论，或关闭批注。只读文件不提供直接修改入口。

局部编辑器审读不等于整章审核完成。推进定稿时，仍执行原章节审读、发现项处置和作者确认流程。

## 6. 保存和结果核对

使用 **Ctrl+S** 或菜单“保存”。“标出未保存改动”显示相对当前基线的修改；标签的未保存标记表示内容尚未落盘。

- **文件已保存**：磁盘更新；草稿保存可能生成下一版，核对更新后的标签与路径。
- **版本已提交／无需提交**：Git 记录已完成或不需要；失败时使用保存提示里的“重试提交”。
- **已交给主控**：保存通知已送达，还须看主 Agent 后续核对，不能直接理解为审核完成。

提交或通知失败不会自动撤回已保存正文。按提示重试对应步骤，不要反复保存相同内容。普通保存的后续工作是核对差异；涉及设定、事实或结构变化时，主控会说明影响和待决定事项。

关闭文档时留意未保存提示，先保存或取消关闭，不要依赖关闭后一定能找回内容。暂时收起侧栏与真正关闭文档不是同一操作。

## 7. 外部修改和冲突

磁盘文件在别处被修改时，编辑器保留你的未保存文字并提示比较。核对两份内容，再按界面选择重新加载或保留自己的编辑；后者以新磁盘版本为保存基线，不代表自动合并完成。

若旧稿已出现更新版本，先打开新稿核对，不反复从旧文件生成分支。更多说明见 [日常写作与恢复](workflows.md)。

## 8. 查找、大纲和排版

| 快捷键／菜单 | 功能 |
| --- | --- |
| Ctrl+F | 查找替换；只读文件不能替换 |
| Ctrl+Shift+O | 标题大纲 |
| Ctrl+1 / 2 / 3 / 0 | 章标题、小节标题、三级标题、正文 |
| Ctrl+B / Ctrl+I | 选区加粗／楷体强调 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销／重做 |
| 右键 → 排版 | 字体、字号、行距、栏宽、首行缩进等偏好 |

段落格式的“场景分隔”插入分隔标记。排版偏好主要影响显示；标题、强调等正文格式会改动文件，需要保存。布局允许时可互换对话与书稿位置；收起或全屏时以宿主布局为准。

## 9. 全文字数与正文汉字数

菜单的“全文”统计当前编辑内容中的非空白可读字符，去掉部分 Markdown 标记，**含标点，也可能含候选事实段及尚未保存的修改**。

正式审读用脚本 `正文统计.汉字数`：读取磁盘当前待审稿，含章标题，排除 frontmatter、候选事实、标点、空白和英文字母。`字符数`、`非空白字符数`是另外两种明确标注的口径。两处数字不必相等，不要拿编辑器全文数判断契约汉字范围。

**旧项目请补充并确认作品契约的章节篇幅**，再启用范围核对。见 [升级步骤与请求示例](upgrade-backup.md#旧项目需要更新作品契约)。越界是现有文本规范发现项，可修改或作者保留，没有新增审批步骤。
