# 第一本书与第一章

先用 [灯塔来信](../../examples/first-book.md) 合成素材练习；准备空白作品工作目录、可用主模型和少量模型额度。此教程会实际调用模型并产生费用。想逐屏对照界面位置与按钮，见 [新手图文教程](beginner.md)。

## 1. 灵感收敛与建书

在对应工作目录的新任务中粘贴练习素材，并发送：

> 按这些素材准备《灯塔来信》。先整理构想七要素给我确认；这是合成练习，一卷三章，先完成第一章。

工作台会先整理构想并请你确认。确认后创建书仓，再选择这本书。成功时应能看到书名、书 id 和当前设计状态；只出现一段聊天文字不代表已经落盘。

## 2. 作品定调与章细纲

> 使用逐部设计流程准备开写内容。作品契约、人物与世界规则、故事骨架、分卷和卷规划都要有真实正文，先呈报给我确认，不要写只有「已确认」标签的占位设计。近期窗口条目名与第一章章名保持一致，再准备第一章细纲。

这是已发布 **preview.5** 的推荐练习路径。`v8` 未发行源码已将快速开写改为「起草真实设计 → 作者过目 → 逐件写入」；安装 preview.5 不会自动带上该修复。若建书后一直卡在世界构建，按 [旧书模块声明排查](troubleshooting.md#旧书卡在世界构建) 处理。

检查主角、冲突、禁区和章节目标。需要调整时直接说明；确认后的文件可在书房查看。第一章细纲至少应明确场景推进、读者承诺和章尾悬念。确认细纲后才进入正文。

## 3. 写稿、审读与修改

> 按已确认细纲写完这一章，并继续完成审读和必要修改。涉及定稿或改变故事方向时请给我确认。

工作台可能连续完成本章内部步骤，也可能因模型错误、审核发现或需要作者决定而停下。失败时读具体原因；不要反复发送“忽略错误继续”。修稿后应根据实际变化重新核对审核证据。

## 4. 定稿

查看正文、审读结论和拟沉淀的事实。只有内容符合意图时才批准定稿。成功应有定稿文件和对应版本提交；有获批沉淀时，还应有故事账本/本书记忆相关变化。不能把“草稿已生成”或“已点击批准”当作“已经定稿”。

## 5. 恢复与导出

关闭任务后重新打开，发送：

> 继续《灯塔来信》，先核对实际书仓进度，告诉我第一章是否已经定稿。

状态应从文件重新校准。然后请求：

> 准备卷一已定稿内容的导出合集和来源清单，先告诉我目标目录和冲突情况。

确认目标后再保存导出。合集只包含指定范围内的定稿，未写完的章节不会被补成正文。成功后检查文件内容与来源清单。

以上步骤应留下可检查文件，而不是只留下模型承诺。遇到问题时保存脱敏的步骤与错误信息，参考 [排错](troubleshooting.md)；不要把整本书或完整会话贴到公开 Issue。
