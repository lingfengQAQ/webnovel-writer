# 数据流、费用与隐私

作品、草稿、账本、记忆和索引以本地文件保存；DSH 另保存自己的设置、凭据与会话。**本地保存不代表运行时完全离线。**

| 功能 | 可能发送的内容 | 控制方式 |
| --- | --- | --- |
| 主模型写作/审读 | 对话、选取的作品材料、工具结果和必要正文 | 在宿主选择服务/模型；只对可接受其数据政策的服务发送材料 |
| 可选嵌入索引 | 定稿切片；查询时发送查询文本 | 提供方默认停用，显式配置启用；变化会触发对应索引更新 |
| 可选场景识别 | 需要识别的章节正文 | 独立启用并选择宿主模型；可取消或重做 |
| 可选重排 | 查询和候选文本片段 | 独立接口/模型，默认关闭；失败回退原顺序 |
| 安装/更新 | 包下载和服务端常规请求信息 | 从官方仓库、npm 与指定 Release 下载 |

模型调用按所选服务计费，重试、长上下文、多轮审读、索引和维度探测均可能增加费用。工作台不提供统一价格或账单保证；在提供方设置额度/预算，先用短合成示例验证。

本插件没有新增独立遥测上传通道；宿主及模型服务的遥测、日志和数据保留应按其实际配置与政策核对，不能据此认为整个运行环境“零遥测”。

启动 token 和 API key 属于秘密。不要把完整启动 URL、设置导出、原书或会话日志贴到公共 Issue。截图前清除这些信息。卸载插件不会自动擦除宿主凭据、会话或作品；删除资产前先确认备份和目标范围。

服务默认只绑定本机回环地址。远程访问需要另外设计认证、网络和密钥管理，本预览版不提供公网部署承诺。漏洞按 [安全政策](../../SECURITY.md) 报告。
