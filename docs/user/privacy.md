# 数据流、费用与隐私

作品、草稿、账本、记忆和索引保存在本地文件里。DSH 另外保存自己的设置、凭据和会话。

> [!IMPORTANT]
> 本地保存不代表运行时完全离线。

| 功能 | 可能发送的内容 | 控制方式 |
| --- | --- | --- |
| 主模型写作/审读 | 对话、选取的作品材料、工具结果和必要正文 | 在 DSH 里选择服务和模型。只向你接受其数据政策的服务发送材料 |
| 参考小说分析 | 选定批次的原文、有界的前序观察，以及分析指令 | 预检和导入只在本地进行。核对实际模型服务和范围，并明确允许之后才发送。范围或服务变化时，重新核对 |
| 可选嵌入索引 | 定稿切片。查询时发送查询文本 | 提供方默认停用。显式配置后才启用。变化会触发对应索引更新 |
| 可选场景识别 | 需要识别的章节正文 | 单独启用，并选择 DSH 里的模型。可以取消或重做 |
| 可选重排 | 查询和候选文本片段 | 使用独立接口和模型，默认关闭。失败时回退到原来的顺序 |
| 安装/更新 | 包下载和服务端的常规请求信息 | 从官方仓库、npm 和指定的 Release 下载 |

模型调用按你选择的服务计费。重试、长上下文、多轮审读、索引和维度探测都可能增加费用。工作台不提供统一价格，也不保证账单。在提供方那里设置额度或预算。先用短的合成示例验证。

> [!NOTE]
> 本插件没有新增独立的遥测上传通道。
> DSH 和模型服务的遥测、日志和数据保留，要按它们的实际配置和政策核对。不能据此认为整个运行环境“零遥测”。

> [!WARNING]
> 启动 token 和 API key 是秘密。
> 不要把完整的启动 URL、设置导出、原书或会话日志贴到公共 Issue。截图之前先清除这些信息。

卸载插件不会自动擦除 DSH 的凭据、会话或作品。删除这些资产之前，先确认备份和目标范围。

清除参考库，不影响原文件和已经保存的点子，也不会撤回模型服务端已经收到的数据。处理步骤和覆盖限制见 [参考小说分析](reference-analysis.md)。故事图谱和流程状态读取本地资料和当前会话记录，不额外调用模型。

服务默认只绑定本机的回环地址。远程访问需要另外设计认证、网络和密钥管理。本版不承诺公网部署。漏洞按 [安全政策](../../SECURITY.md) 报告。
