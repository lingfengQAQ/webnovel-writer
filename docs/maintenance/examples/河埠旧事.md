# 第一章 退潮以前

林岑回到镇上那天，修鞋铺的卷帘门只拉起半截。她弯腰钻进去，箱轮卡在门槛的裂缝里，母亲伸脚抵住箱底，往上一托。

“怎么不先打电话？”

“打了。你没接。”

母亲从围裙口袋里摸出手机，屏幕上沾着一点黑胶。她拿拇指蹭了两下，才看见三个未接来电。

店里还是那股皮革混着汽油的味道。靠窗的缝鞋机盖着旧床单，床单下露出半只踏板。父亲去世已经四个月，母亲把他的茶杯收了，机器却留在原处。林岑把箱子推进柜台，碰落一双儿童凉鞋，鞋底用粉笔写着一个“陈”字。

“这个还没来拿？”

“放下。胶没干透。”

林岑把鞋摆回去。她请了两天假，车票买在后天下午。房东说下月要整修这一排铺面，续租得一次交半年。电话里母亲只说知道了，等她问起钱，信号就不好起来。

柜台上的收据压在玻璃下面。林岑抽出来看了一眼，半年租金旁边，母亲用圆珠笔写了个小小的“欠”。

“妈，跟我过去住吧。”

母亲没抬头，把一截断线从针眼里抽出来。

“你那屋不是跟人合租？”

“月底能换。”

她说得太快。那间便宜一点的一居室离公司两个半小时，中介昨晚已经催她付定金。母亲把针举到灯下，眯着眼穿线。林岑伸手去接，母亲侧过身，线头在嘴唇上抿了抿，穿过去了。

“今天先把东西收一收。”林岑说，“真舍不得的，都带走。”

母亲把鞋帮翻到里侧，没有接话。

午后，隔壁卖菜的周姨推门进来，塑料袋挂在腕上，里面两根丝瓜已经压弯了。她看见林岑，先问路上热不热，又从袋底摸出一双男式布鞋。

“还是后跟。老头子走路爱拖，磨得快。”

母亲接过去，指腹摸了摸磨穿的地方。

“明天下午来拿。”

林岑站在柜台后，手里还捏着那张收据。

“周姨，我们可能要关店了。”

周姨看了母亲一眼，笑容停了一下，随即伸手来拿鞋。“那不修也行，我让他换新的。”

母亲把鞋往自己这边挪了挪。

“补个后跟，不费事。”

周姨走后，店里安静下来。对街电焊的声音断了，林岑听见母亲用锥子穿透鞋底，一下，再一下。

“你答应她明天。明天再来一个呢？”

母亲没有停手。

“总得把接下的活做完。”

“我不是说这双鞋。”

锥子停在半空。母亲用围裙擦了擦手，把玻璃下的收据拿过去，沿原来的折痕折好，收进抽屉。抽屉合拢时，里面一串钥匙碰得叮当响。

“我知道。”她说。

林岑准备好的话反而说不出来了。她本来要算房租、水电，算母亲每天弯腰十几个小时能挣多少钱。可母亲知道。四个月里，每个月少了多少钱、多少人路过时会往空着的缝鞋机上看一眼，她比林岑清楚。

傍晚涨过的水退下去，街尾渡口露出两级湿漉漉的石阶。母亲起身拉灯绳，让林岑先去吃饭，自己把这双鞋补完。

林岑没走。她从柜台底下找出父亲用过的小凳子，拂掉座面上的皮屑。凳腿有一只短些，坐下去晃了一下。

“要哪种底？”她指了指墙上的材料袋。

母亲抬头看她。

“最下面那包。别拿成黑的，他这双是棕的。”

林岑取下袋子，倒出两块橡胶后跟。母亲把鞋放到她膝上，用粉笔沿旧底画了一道线。

“先剪大一点。剪小就补不回来了。”

剪刀比林岑记得的沉。她剪到拐角，偏出去一点，停住，看向母亲。

“没事，还能磨。”

街上的店铺陆续亮灯。林岑把手机调成静音，屏幕朝下放在柜台上。中介又发来一条消息，隔着玻璃，振动声很短。

她把第二块鞋底递过去。

“后天的车我改晚一班。”

母亲接过来，比在鞋上，看了好一会儿。

“别耽误上班。”

“周一才上班。”

母亲点点头，把剪刀留在她手边。灯绳晃动的影子扫过墙上的旧价目表，两个人谁也没有再提关店的事。
