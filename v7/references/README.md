# 知识库（references/）

供脚本按声明路由查表的写作知识真源（spec 0.15 §5/§6.3/§7），随 installer 装到 `.webnovel/references/`。

## 结构

- `路由.csv`——题材/流派两维路由：名称、维度、题材、条目路径、别名（`;` 分隔）。建书归一别名的唯一依据。
- `题材/`——canonical 题材一个一份。front matter：名称 / 恩怨清算默认 / 毒点；正文三节：骨架约定 / 读者预期 / 毒点展开。建书蒸馏消费。
- `流派/`——可叠加在题材上的写法流派。front matter：名称 / 适用题材 / 毒点；正文三节同题材。建书蒸馏消费。
- `节拍/`——章级情绪/节奏曲线段（PA-xxx）。front matter：编号 / 名称 / 一句话 / 关键词 / 适用题材 / 毒点；正文三节：规划这一章时 / 落笔时 / 审稿时。细纲声明 `本章节拍：` 路由。
- `场景/`——单场戏技法。front matter 多一组 `关键词`（脚本扫卷纲与上一章结尾出候选）；细纲声明 `本章场景：` 路由（可多值）。
- `追读/`——章尾/章内钩子纪律。细纲声明 `章尾钩子：` 路由。

## 内容纪律（新增/修改条目必守）

- 只写结构与禁忌（什么必须发生、什么绝不能发生），不写示例情节、人名书名；示例只作毒点反例。
- 毒点一律「XX不得YY」句式，只判叙事结果与主角行为，禁止「不得出现X角色」式禁人设条款。
- 格式由 `test/references/format.test.js` 机器校验；内容质量走逐条独立审查（记录见任务 07-07-knowledge-layer-rework 的 research/content-review/）。
