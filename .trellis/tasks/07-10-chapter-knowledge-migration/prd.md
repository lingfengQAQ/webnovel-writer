# 篇章知识重分类与策展

## Goal

重划节拍、场景、技法、追读边界，清理当前节拍与场景混维，并从 v6 场景写法、写作技法、桥段套路中逐条筛选、抽象和重写可复用原理。

## Requirements

- 前置依赖：父任务最终规划与十维边界已冻结；运行时框架的章级候选、细纲声明、精准切片和近期历史接口已实现并通过行为测试。
- 节拍只描述张力/情绪随时间变化；场景只描述事件互动容器；技法描述可迁移呈现/组织方法；追读描述未来未闭合压力。
- 结构方法进入 `技法` 子类；兑现改为章级契约字段，不建目录。
- v6 桥段套路不得整体迁入或新增 `本章桥段`；逐条拆入场景、节拍、追读、技法、创意约束，无法抽象者删除。
- 清理当前 102 节拍、16 场景、10 追读的近重复、错维和未决项。
- 每条知识只有一个正式维度归属；跨维需求通过组合或拆分解决，不复制条目，也不预设无消费者的协同维度字段。
- 章级知识随细纲整体确认，允许删除、替换、混合、拒绝和自定义；近期使用历史只做软性降权、机械重复提醒和变体说明。
- 每条保留、拆分或改写经过独立内容审查和开发阶段策展签收。

## Acceptance Criteria

- [ ] 四维准入与排除规则能够稳定裁决现有边界样本。
- [ ] 章级候选按本章真实问题和各维度实际消费字段筛选，不展示全量菜单，也不要求所有维度采用统一字段。
- [ ] `规划这一章时`、`落笔时`、`审稿时`均有真实调用者。
- [ ] 章级知识随细纲整体确认；重复只在功能与落地方式相似且无递进时触发软提醒，不硬禁合法复用。
- [ ] v6 场景96、技法104、桥段108条候选素材均有策展裁决记录；无成品剧情模板进入运行时库。

## Notes

- 创意约束条目的实际落盘由书级知识任务负责，本任务只标注桥段来源中的候选去向。
- 启动前补齐自身 `design.md` 与 `implement.md`；按节拍、场景、技法、追读分批提交，回滚保留运行时自定义降级和已冻结的章级声明契约。
