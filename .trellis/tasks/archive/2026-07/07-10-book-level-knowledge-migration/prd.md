# 书级知识校准与策展

## Goal

按已冻结的十维治理规范，校准现有题材与流派的可调用边界，恢复 v6 反套路和复合题材的有效能力，并建立正式 `创意约束/` 内容层，使建书能把通用知识蒸馏为差异化、可执行、可审查的本书 `作品契约/作品契约.md`。

本任务追求的是调用价值和边界清晰，不追求条目数量。完成后，新增书级知识应能依据同一套准入、归位和审查规则稳定扩充，而不会因固定路由或固定创意模板导致作品同质化。

## Background

### 已实现运行时

- 运行时已将题材、流派、创意约束注册为作品契约三维；创意约束索引只消费 `名称` 与 `一句话`（`v7/src/knowledge/index.js:10-29`）。
- `knowledge-pack` 已支持 `类型 + 副题材 + 流派` canonical 归一；路由只改名称并给兼容提醒，不选择创意约束或具体作品方案（`v7/src/knowledge/index.js:100-158`）。
- `knowledge-query` 已按真实未决问题查询正式知识，每维最多返回三条；没有机械信号时返回空集，允许继续对谈和自定义（`v7/src/knowledge/index.js:239-277`）。
- 建书调用已要求只在真实未决的创意问题上查询 `创意约束`，把最终选择、本书化变体和融合协议写进作者确认的作品契约（`v7/skills/webnovel-writer/SKILL.md:21`）。
- 运行时框架已经移除旧 `文风/题材流派指导.md`、恩怨清算枚举和当前通用题材/流派回读；本内容任务不得恢复这些旧机制。

### 当前内容基线

- 正式库当前有题材 16 条、流派 22 条；`创意约束/` 尚无正式条目。题材和流派 canonical 名称、别名、兼容题材及路径由 `v7/references/路由.csv` 提供。
- 07-07 与 07-08 已签收内容全部属于本任务输入，不重新撤销历史签收；本轮依据新宪章做二次边界校准和字段清理。
- 已知压力样本包括：末世与科幻内容重叠；洪荒流、克苏鲁、诡秘流混合世界规则与推进引擎；部分题材别名实际属于流派、设定或更窄市场标签；部分流派兼容题材范围过窄或以无信息量的 `全部` 表达。
- v6 创意来源位于 `webnovel-writer/skills/webnovel-init/references/creativity/`，共九份：`anti-trope-xianxia.md`、`anti-trope-urban.md`、`anti-trope-rules-mystery.md`、`anti-trope-game.md`、`creativity-constraints.md`、`creative-combination.md`、`inspiration-collection.md`、`market-positioning.md`、`selling-points.md`。这些文件只是候选素材，不是待兼容格式。
- v6 复合题材材料使用固定 `7:3`、`60-70% / 30-40%` 和“每 N 章一次”模板（`docs/guides/genres.md:42`、`webnovel-writer/templates/output/复合题材-融合逻辑.md:6-22`、`webnovel-writer/skills/webnovel-init/references/creativity/creative-combination.md:163-168`）；其共同冲突、规则兼容/隔离、介入条件和职责分工仍有可保留价值。

### 审计发现（规划输入）

- `resolveLabel` 按名称/别名在单一维度内一对一命中，不能理解复合输入或跨维词（`v7/src/knowledge/index.js:88-96,109-138`）。因此 `仙侠` 的“宗门流”、`历史` 的“争霸权谋/武侠”、`种田` 的“基建/经营/慢生活”、`快穿` 的“攻略系统/小世界/任务者”等会把流派、世界空间、机制或结构标签静默压成题材；复合别名如“玄幻修仙”也可能丢失第二维。
- 题材正文中已有明显的长期引擎或结构内容：`题材/种田.md:11-14` 的资源循环、`题材/快穿.md:11-14` 的任务循环、`题材/游戏.md:12-24` 的赛事推进，须按主要承诺与主要调用者重判，而不是因为现有文件存在就默认保留原维度。
- `末世` 与 `科幻` 都承载文明崩坏、资源危机和进阶求生（`.trellis/tasks/archive/2026-07/07-08-kb-ima-distill-integration/research/content-review/批C-题材.md:12-14,40-58`），应在本任务形成唯一可执行的内容边界；不能仅依靠路由键不同来掩盖契约重叠。
- 现有流派 front matter 的 `适用题材` 由路由表重复提供，且 `毒点` 与正文 `毒点展开` 形成双真源；运行时索引只读取流派 `名称`（`v7/src/knowledge/index.js:21-22,147`）。本任务须记录字段处置和跨任务改动点，但不得私自扩展公共 schema。
- 多个现有条目仍以固定章数、固定阶段、固定配比或固定揭露链描述方法（例如退婚、系统、直播、重生、追妻、无敌等），应改写为条件、递进和失败判据；数量和模板化程度都不是保留理由。
- 2026-07-18 官方平台对照确认：起点、QQ 阅读、纵横和七猫均稳定提供武侠、现实、军事、体育类入口；番茄、红袖和晋江同时证明平台货架会混合题材、主题、关系、情节和篇幅，不能原样复制。完整证据见 `research/主流网文题材平台对照.md`。

## Confirmed Decisions

- `类型` 是单一主题材；`副题材` 只能来自 canonical 题材集合；`流派` 独立多选。固定路由只负责名称归一和兼容提醒。
- 题材回答“读者进入什么基本虚构空间、核心承诺是什么”；流派回答“故事靠什么可重复引擎长期推进”；创意约束回答“本书主动接受什么限制或代价来阻断默认解法”。
- 反套路不是把套路反着写，而是能持续制造决策压力的限制、代价或规则变化；每条必须有长期驱动和防绕过条件。
- 建书先理解作者已有构想，只对未决部分提供候选；候选用于组合、改造、拒绝或自定义，不得由题材/流派路由导出唯一答案。
- 主题材负责核心读者承诺和主线因果，副题材必须有明确介入条件和独立贡献；复合题材必须形成融合协议，不能只是两个标签并列。
- 复合题材不保留通用固定 `7:3`、`60-70% / 30-40%` 或“每 N 章一次”默认；只有作者主动需要节奏配额时，才在本书契约中记录专属数值、统计对象、使用目的和失效条件。
- 最终书级真源是作者确认的 `作品契约/作品契约.md`。通用题材、流派和创意约束只在建书或重大改纲时作为蒸馏材料，不被逐章回读。
- 通用知识只在开发阶段策展，不向作品作者开放投稿、评分、自动扩库或作品知识晋升流程。
- v7 尚未生产，本任务不做旧书迁移、旧路径双读、旧 schema 兼容或内容墓碑。
- 本任务不得自行改变已冻结的十维边界、调用阶段或运行时 schema；若现有接口确实无法消费必要知识，停止对应内容批次并回父任务发起架构变更。
- 在现有题材集合上新增 `武侠 / 现实 / 军事 / 体育` 四个 canonical 题材；`历史` 不再把武侠作为别名，`游戏` 不再把普通竞技作为同义题材。
- `竞技` 不进入题材层；它是可跨体育、电竞和其他赛事的长期推进引擎，只能在通过流派准入检查后建立流派条目。
- 新增 `灵异` canonical 题材：承载超自然威胁、禁忌、仪式、生存和未知感；`悬疑` 收窄为谜题、线索公平与真相追索。`惊悚/恐怖` 是体验词，输入时必须继续辨别谜题承诺与超自然承诺，不自动映射任一题材。
- `快穿` 从题材移到流派：它定义跨世界接取任务、执行、结算和进入下一单元的长期推进引擎，不定义单一基本虚构空间。建书识别快穿意图后必须继续确认本书核心读者承诺，形成实际主题材 + 快穿流。
- `种田` 从题材移到流派：它定义生产、加工、交换、积累和再投入的长期经营引擎，可跨古言、年代、都市、玄幻和末世使用。建书识别种田意图后按实际世界与核心承诺确定主题材，再组合种田经营流。
- 本轮暂不新增 `青春` 题材；它保留为后续候选。“青春/校园”不是 `现言` 或 `都市` 的固定别名，建书遇到该输入时须依据关系、成长、现实空间或幻想学院等实际承诺继续辨别。
- `衍生` 保留为题材层唯一明确的来源关系特例，不新增来源维度或字段。选择 `类型=衍生` 时必须同时选择至少一个实际世界题材作为副题材，作品契约同时保存原作识别点、改写边界和新增变量；只选择“衍生”不得完成建书。

## Requirements

### R1 题材校准

- 逐条审计现有题材（其中 `快穿 / 种田` 已确认移出）及已确认新增的 `武侠 / 现实 / 军事 / 体育 / 灵异`，定义核心虚构空间、核心读者承诺、必要边界、排除边界、相邻题材分界和 canonical 别名。
- 对每条给出保留、锐化、改名、拆分、合并或删除裁决；不得因市场常用词而把流派、设定机制或受众标签误作题材别名。
- 重点裁决末世/科幻、都市/现言/现实、历史/古言/年代、玄幻/仙侠/奇幻/幻言、游戏/体育、悬疑/灵异等相邻组合，证明它们能按核心承诺稳定选出单一主题材。
- 复合输入或跨维词不得静默归一；若现有解析器无法表达真实的主题材+副题材选择，只记录为父任务/集成审计的架构变更候选，不在本任务中临时发明兼容语法。
- 新增题材须分别通过独有问题、独有动作、独有失败模式、明确触发和可区分五项准入；至少验证武侠/历史/仙侠、现实/都市、军事/历史、体育/游戏四组边界。
- 悬疑/灵异必须以“真相是否承担核心兑现、未知是否允许保留、超自然规则是否作为真实威胁”稳定分界；两者可作主副题材组合，但不能用一个文件提供互相冲突的默认承诺。
- 衍生条目只承载原作识别、改写边界和新增变量的来源契约；实际世界规则由必选副题材提供，不得在衍生正文复制仙侠、都市、游戏等题材知识。

### R2 流派校准

- 逐条审计现有 22 个流派，并把从题材移入的 `快穿流 / 种田经营流` 纳入同一审计，验证 24 个基础流派是否具有可跨题材复用的长期推进引擎，以及其与题材、设定、人物和技法的排除边界。
- 将 `快穿` 纳入流派审计，明确其与一次性异时空身份转换的 `穿越流`、以危险副本与元成长为核心的 `无限流` 的选择边界；不得复制原题材正文后改名了事。
- 将 `种田` 纳入流派审计，保留经营复利引擎并删除具体世界默认；依据独有问题、动作和失败模式决定保留单一“种田经营流”还是拆出可独立调用的势力建设候选，不预设拆分数量。
- 重点裁决洪荒流、克苏鲁和诡秘流：流派条目只保留推进引擎与读者风险，可独立调用的世界规则转交故事对象知识任务，不在两个目录复制。
- 校准 `路由.csv` 的 canonical 名称、别名和兼容题材。兼容范围只用于提醒，不替作者删除选择；无信息量的 `全部` 不得作为内容占位。
- 对明显不是同义词的“封神/上古、规则类、白月光、虐文、校园成长、赛博朋克、四合院”等收窄或移除别名；`竞技` 只作为流派候选，不能因平台聚合词“游戏竞技”成为题材。

### R3 v6 创意资产逐条裁决

- 对九份 v6 创意来源建立可追溯裁决表，记录来源片段、主要问题、目标维度、近重复对照和保留/重写/拆分/合并/删除理由。
- 只收编可迁移的限制、代价、长期驱动与防绕过机制；评分、热门排序、固定创意包 schema、时效平台画像、固定人物/剧情组合和具体案例删除。
- 反派镜像等人物设计转交 `人物/`，规则设计转交 `设定/`，开篇钩子和表现方法转交篇章知识任务；本任务不跨目录代写其他子任务内容。

### R4 创意约束正式内容层

- 建立 `v7/references/创意约束/` 正式条目；条目数量由真实独有问题决定，不设最低数量指标。
- 每条必须说明被挑战的常规、决策压力、长期驱动、防绕过条件、适用/迁移/禁用条件，以及生成侧与审查侧各自需要的判断依据。
- front matter 只保留现有消费者读取的 `名称` 与 `一句话`；适用、迁移和禁用条件默认写正文，不新增无消费者字段。
- 条目必须原子化、去示例化、去题材换皮重复；同一约束能跨题材迁移时只保留一个 canonical 条目。
- 不把普通毒点、恩怨道德预设或固定数字当作创意约束；只收编会持续改变决策和代价的机制。

### R5 复合题材融合规则

- 形成建书可直接蒸馏的融合规则，至少覆盖：共同核心冲突、主题材承诺、规则兼容/隔离、副题材介入条件、主副线职责、独立贡献、冲突解决和风险清单。
- 融合规则必须能区分“副题材真实改变因果与选择”与“只换皮或偶尔露出标签”，并能在编辑审中核对承诺是否失焦。
- 不把主题材、副题材和流派重新揉成固定组合包；同一主副题材应允许形成不同融合协议和创意约束。
- 删除旧材料中的通用固定占比、固定章数和固定露出频率；若本书确需量化节奏，必须同时写明统计对象、使用目的和失效条件，不将该数值回写为通用知识默认。

### R6 作品契约调用闭环

- 每条题材、流派和创意约束都须明确建书生成侧读取什么、作品契约保存什么、编辑审依据什么判断失败。
- 内容只能蒸馏进现有作品契约字段和正文小节，不得恢复恩怨清算档位，也不得要求下游逐章回读通用书级条目。
- 使用至少两组相同题材/流派输入验证：作者意图或创意约束不同能够形成实质不同的融合协议、差异化点和冲突规则。

### R7 策展、审查与回滚

- 题材、流派、创意约束分批落地；每批都有近重复检查、格式检查、独立内容审查、逐条裁决记录和开发治理签收。
- 正式条目不得包含具体人名书名、可直接复刻的成品情节、固定评分或无消费者字段。
- 回滚按内容批次撤销，不反向修改已冻结运行时 schema，也不引入兼容层。

## Out of Scope

- 不处理设定、人物、命名、节拍、场景、技法或追读条目的实际策展；只记录并转交从书级旧资产拆出的候选。
- 不改变十维宪章、调用者矩阵、作品契约 schema、候选数量、查询算法或持久化流程。
- 不恢复 v6 固定创意包、评分系统、平台画像、具体案例或 AI 主动整库语义检索。
- 不处理旧书或旧 v7 书仓迁移，不建设作者侧通用知识扩库流程。
- 不在本轮建立 `青春` 正式题材；后续只有在独立内容与调用证据成熟时重新走准入检查。
- 不为衍生来源关系新增第十一维、公共字段或独立书仓目录。
