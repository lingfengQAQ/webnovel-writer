# 创意约束内容审查

> 审查日期：2026-07-18
> 审查对象：由九份 v6 来源聚类后通过准入的 11 个正式条目。

## 逐条准入

| 条目 | 独有问题 | 独有动作 | 独有失败 | 结论 |
|---|---|---|---|---|
| 不可逆代价 | 优势没有真实价格 | 绑定不可恢复损失并关闭后续选项 | 代价可退款或不影响选择 | 通过 |
| 条件触发窗口 | 关键手段随时可用 | 创建、等待或保护可验证窗口 | 窗口靠巧合或危机后改规则 | 通过 |
| 优势带可利用弱点 | 优势没有对手互动面 | 让同源缺口可被观察和利用 | 弱点只在设定表或临时免疫 | 通过 |
| 核心优势可竞争 | 关键筹码永久主角专属 | 建立共享、转移、夺取与所有权选择 | 他人获得的是无效仿制品 | 通过 |
| 信息有限且会失效 | 先知与规则信息永久正确 | 限定范围并让行动推动信息过期 | 缺口只在作者需要反转时出现 | 通过 |
| 知识转化有门槛 | 知道答案即可直接成功 | 强制经过材料、组织、验证和制度过程 | 门槛被贵人或万能资源整体跳过 | 通过 |
| 成功解法会被适应 | 同一方案无限复用 | 让可观察成功改变对手和环境 | 适应只是无依据免疫或抬数值 | 通过 |
| 不存在无损选择 | 所有责任都能同时保全 | 建立不可兼得的合法目标并延续损失 | 隐藏第三路取消全部代价 | 通过 |
| 收益同步扩大风险 | 成功只增加安全与资源 | 让收益同源产生债务、暴露、责任或反制 | 风险随机出现或被新奖励抵消 | 通过 |
| 稀缺资源总量守恒 | 关键资源按需增发 | 固定有效范围内总量并追踪分配后果 | 主角总能发现额外来源 | 通过 |
| 核心问题不可由优势直接解决 | 优势替角色完成主线 | 明确优势只能创造条件，核心答案仍需行动 | 关键场景直接代打或临时失灵 | 通过 |

## 近重复裁决

| 相邻项 | 唯一分界 |
|---|---|
| 不可逆代价 / 收益同步扩大风险 | 前者在调用优势时损失既有资源；后者在获得收益后新增外部压力与责任 |
| 条件触发窗口 / 核心问题不可由优势直接解决 | 前者限制何时可用；后者限制能力能解决到哪一步 |
| 优势带可利用弱点 / 核心优势可竞争 | 前者改变优势自身的攻防面；后者改变优势的持有格局 |
| 核心优势可竞争 / 稀缺资源总量守恒 | 前者关注所有权可转移；后者关注总份额与分配取舍 |
| 信息有限且会失效 / 知识转化有门槛 | 前者不知道完整答案或答案会过期；后者知道答案但缺少实现条件 |
| 成功解法会被适应 / 收益同步扩大风险 | 前者由对手或环境学习旧方案；后者由成功本身扩大暴露、债务或责任 |
| 不存在无损选择 / 不可逆代价 | 前者在互斥目标间选择损失；后者为调用某项优势支付固定不可恢复价格 |

## 触发与迁移检查

- 每条 `一句话` 都包含可展示的机制摘要和至少两个作者常用问题短语，不新增关键词字段。
- 11 组真实未决问题均能首位命中目标条目，单次查询仍不超过三条。
- 每条正文都说明适用、迁移和禁用条件；通用范围未写无信息量的“全部”。
- 没有条目按题材固定路由；同一题材可以按真实问题命中不同约束，也可以拒绝或自定义。

## 内容纪律检查

- front matter 仅 `名称 / 一句话`，正文四节齐全。
- 未发现旧 ID、评分、热门排序、平台画像、具体人名书名、固定人物组合或可复刻情节。
- 未发现固定比例、固定章频、旧关系结算默认或题材换皮重复。
- 11 项全部通过，无阻断发现。
