# 书级知识校准与策展

## Goal

按十维治理规范校准题材与流派边界，恢复 v6 反套路和复合题材能力，并建立可调用、可蒸馏、可审查的 `创意约束/` 内容层。

## Requirements

- 前置依赖：父任务最终规划与维度宪章已冻结；运行时框架的书级 schema、作品契约结构和候选接口已实现并通过行为测试。
- 重审现有题材/流派边界、别名和主辅题材兼容关系。
- 将 v6 反套路库仅作为候选素材，逐条去示例化、原子化并重写为限制/代价/差异化驱动；不得照搬旧格式或形成新的反套路模板。
- 建立复合题材融合规则：主辅承诺、兼容/隔离、介入条件、主副线分工与风险。
- 书级知识最终蒸馏为 `作品契约/作品契约.md`，完全替代 `文风/题材流派指导.md`；契约包含核心读者承诺、融合协议、创意约束、差异化、冲突与关系结算原则、专属毒点和节奏兑现参数。
- 每条内容经过近重复核查、独立内容审查和开发阶段策展签收；不向作品作者开放通用知识扩库入口。

## Acceptance Criteria

- [ ] 题材、流派、创意约束三维边界可执行且无路由歧义。
- [ ] 建书能够生成多套差异化创意约束候选，并产出本书专属融合契约。
- [ ] 建书缺少结构完整且经作者确认的 `作品契约.md` 时不得完成；旧题材流派指导和恩怨清算枚举已完全移除。
- [ ] v6 反套路独有知识有逐条保留、合并、重写或删除记录。
- [ ] 无具体剧情模板、人名书名或可直接复刻案例进入运行时条目。

## Notes

- 本任务不处理设定、人物、命名或章级知识策展。
- 启动前补齐自身 `design.md` 与 `implement.md`；内容按题材、流派、创意约束分批提交，回滚只撤销对应内容批次，不反向修改已冻结的运行时 schema。
