# 题材与流派逐条裁决

> 裁决日期：2026-07-18
> 依据：任务 PRD、`v7/docs/knowledge/维度宪章.md`、`调用者与字段矩阵.md`、`策展规则.md` 及 `research/主流网文题材平台对照.md`。

## 1. 统一处置

- 题材只保存基本虚构空间、核心读者承诺、选择边界和失败模式。
- 流派只保存可重复的长期推进引擎、组合边界和失败模式。
- 题材/流派 front matter 的 `毒点` 删除；流派 `适用题材` 删除，兼容范围只留 `路由.csv`。
- 固定章数、固定阶段、固定比例、人物模板和关系结算默认全部删除，改写为触发条件、因果递进和可观察失败。
- 别名只有在无需继续辨别也会得到同一 canonical、且不会丢掉另一维信息时保留。

## 2. 题材裁决

| 来源 | 动作 | 最终 canonical | 唯一职责与主要分界 |
|---|---|---|---|
| 都市 | 锐化 | 都市 | 当代城市中的身份、资源、职业或超常杠杆；与现实、现言分界 |
| 现言 | 锐化 | 现言 | 当代亲密关系为核心承诺；事业与社会线只在改变关系选择时进入 |
| 年代 | 锐化 | 年代 | 特定近现代时期的物质与制度条件；四合院等具体空间不作别名 |
| 历史 | 锐化 | 历史 | 历史时期公共制度与时代进程；剥离武侠、军事和古言职责 |
| 古言 | 锐化 | 古言 | 古代或仿古社会的关系、家族与生活承诺；不兜底朝代政治 |
| 玄幻 | 锐化 | 玄幻 | 东方幻想力量秩序与成长；剥离修仙复合别名和固定升级模板 |
| 仙侠 | 锐化 | 仙侠 | 修炼、求道、因果与超脱；宗门只是一类组织，不作别名 |
| 奇幻 | 锐化 | 奇幻 | 非东方修真范式的魔法与异世界文明；魔法、骑士等单元素不作别名 |
| 幻言 | 锐化 | 幻言 | 幻想空间中的关系与情感承诺；世界/力量主导时归其他幻想题材 |
| 科幻 | 锐化 | 科幻 | 科学技术或理性推演改变个体与文明；剥离末世求生和赛博朋克单标签 |
| 末世 | 锐化 | 末世 | 文明崩坏、生存稀缺与秩序重建；灾变成因不决定是否科幻 |
| 悬疑 | 拆边界 | 悬疑 | 公平线索、谜题与真相追索；灵异、惊悚不再作别名 |
| 游戏 | 锐化 | 游戏 | 游戏规则、虚拟空间、玩家身份及电竞语境；普通竞技不作别名 |
| 衍生 | 例外保留 | 衍生 | 原作识别点、改写边界与新增变量；必须配实际世界副题材 |
| 快穿 | 移动并重写 | 快穿流 | 跨世界任务循环属于长期推进引擎，不是基本虚构空间 |
| 种田 | 移动并重写 | 种田经营流 | 生产、交换、积累与再投入属于经营引擎，可跨多种世界题材 |
| 无旧条目 | 新增 | 武侠 | 江湖、门派、武学、侠义与人情秩序；与历史、仙侠分界 |
| 无旧条目 | 新增 | 现实 | 真实制度、职业、家庭与公共生活因果；与广义都市分界 |
| 无旧条目 | 新增 | 军事 | 军队组织、任务、战术、后勤与战场代价；时代不限定为历史 |
| 无旧条目 | 新增 | 体育 | 运动规则、训练、赛季、队伍与职业结果；与游戏、普通竞技分界 |
| 悬疑旧别名及平台证据 | 新增 | 灵异 | 超自然威胁、禁忌、仪式、生存与可保留未知；与真相追索分界 |

最终题材为 19 个：都市、现实、现言、年代、历史、古言、武侠、军事、玄幻、仙侠、奇幻、幻言、科幻、末世、悬疑、灵异、游戏、体育、衍生。

## 4. 高风险别名裁决

| 原别名或输入 | 裁决 | 理由 |
|---|---|---|
| 玄幻修仙、修仙/玄幻 | 删除 | 复合输入会丢失题材选择 |
| 宗门流 | 删除 | 组织/推进方式，不是仙侠同义词 |
| 魔法、骑士 | 删除 | 单一设定元素不能决定奇幻题材 |
| 赛博朋克 | 删除 | 技术社会子类型，需辨别科幻承诺与设定 |
| 争霸权谋、武侠 | 从历史删除 | 分别是推进方式和独立题材 |
| 惊悚、恐怖 | 不路由 | 体验词，须辨别悬疑或灵异承诺 |
| 灵异 | 改为 canonical | 与悬疑分担不同核心兑现 |
| 竞技 | 从游戏删除 | 可跨体育、电竞及其他赛事的推进方式候选 |
| 四合院 | 删除 | 具体空间与时代标签，不等于年代题材 |
| 基建、经营、慢生活 | 从种田删除 | 相邻但不等同于种田经营引擎 |
| 攻略系统、小世界、任务者 | 从快穿删除 | 机制、空间和身份词，不能单独决定快穿流 |
| 封神、上古 | 从洪荒流删除 | 来源时期或素材，不是长期引擎同义词 |
| 规则类 | 从规则怪谈删除 | 范围过宽，可能指任意规则设计 |
| 白月光 | 从替身文删除 | 人物功能，不必然形成替身关系 |
| 虐文、先虐后甜 | 从追妻火葬场删除 | 情绪/关系走向不能保证修复引擎成立 |
| 校园成长 | 从学院流删除 | 成长主题与学校空间不足以证明制度化引擎 |
| 青春、校园 | 不路由 | 本轮不建青春题材，须继续辨别核心承诺 |

## 5. 转交记录

- 洪荒神话实体与时间线规则、克苏鲁高位存在规则、诡秘途径和仪式规则：转故事对象知识任务的设定候选。
- 关系条目中的角色弧与镜像人物方法：只保留流派所需的关系推进引擎，其余转人物候选。
- 章级存量中有 11 个节拍条目的 `适用题材` 仍使用“快穿/种田”，`PA-107-微兑现` 正文也仍把“种田”并列为题材。篇章知识任务须在逐条策展时删除无消费者字段或改为真实流派触发，不在本书级任务越界改写节拍内容。
- 固定揭露步骤、固定章数和具体表现手段：不进入书级条目；可迁移方法转篇章知识任务复核。
