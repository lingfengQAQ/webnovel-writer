## 字段说明（生成后可删除本节）

每章固定使用下列字段，**顺序与字段名不要改动**——下游 `write` / `review` 与项目自定义检查脚本按字段名定位。

| 字段 | 说明 |
|------|------|
| 目标 | 本章主角想达成什么（一句话） |
| 阻力 | 挡住他的是什么 |
| 代价 | 达成或未达成各付出什么 |
| 时间 | `{时间锚点} \| 约 {章内跨度} \| {与上章时间差} \| {倒计时状态}` |
| 爽点 | 本章兑现类型；无则写 `无` |
| Strand | 本章所属线索；同时标注反派层级 |
| 视角/主角 | 本章视角人物 |
| 关键实体 | 本章出现的关键人 / 地 / 物 |
| 本章变化 | 本章结束时，世界或人物**不可逆**地变了什么 |
| 章末未闭合问题 | 读者读完仍悬着的那个问题 |
| 钩子 | 断章方式（类型 + 一句话） |
| CBN / CPNs / CEN | 结构化节点，格式 `主体 \| 动作/变化 \| 对象/结果` |
| 必须覆盖节点 | 最多 4 个，建议 `CBN + CEN + 1~2 个核心 CPN` |
| 本章禁区 | 不超过 5 条，只写本章绝对不能发生的硬禁区 |

> **项目自定义字段**：若项目有额外的必填栏（人物弧线落点、动机依据、信息状态等），
> 统一追加在 `本章变化` 之后、`章末未闭合问题` 之前，并在项目文档中说明其判据。
> 本模板不预设这类字段，但保留该位置，避免各卷插入位置不一致。

## 编写约束

1. **每章固定 1 个 `CBN`、2-4 个 `CPN`、1 个 `CEN`**；`CPNs` 按时间顺序排列。
2. **相邻章 `CEN -> 下一章 CBN` 必须逻辑承接**（首章与末章除外）。
3. **相邻章不得重复同一场戏**：上一章 `目标` / `代价` / `本章变化` 里已经完成的事件，
   不得再作为下一章的 `CPN` 出现。确需跨章延续时，下一章须写明它承接的是上一章的哪个节点，
   而不是重新执行一次。
4. **时间必须自洽**：`时间锚点` 单调递增；`与上章时间差` 与上一章的 `章内跨度` 不冲突；
   倒计时按实际经过天数推进。若某章因订制工期、路程、约定日期等原因存在客观等待期，
   该等待期必须体现在时间字段中，且等待期内的章节不得执行需要等待完成后才能做的事。
5. **本章禁区只写硬禁区**，不写风格类建议。
