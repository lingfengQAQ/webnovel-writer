# 素材与制作

角色与坐姿动画由项目作者提供，来自其生成结果（2026-09-29）。当前采用作者确认手部正常的单条 `whalegirl_video.mp4`：834×1112、24fps、721 帧，约 30 秒。七个动作均从这一条连续视频剪出；旧独立七段及制作脚本保留用于回退。

代码遵循本仓 GPL-3.0-only。生成素材的来源与校验记录在 assets/manifest.json；这些记录说明素材来源，不另行声称第三方素材的所有权或模型服务许可。

开发者可从作者保留的原文件重新制作：

```sh
python scripts/prepare-continuous-media.py /path/to/whalegirl_video.mp4
```

开发环境依赖 av、opencv-python、numpy、Pillow、imageio-ffmpeg，实际版本及脚本哈希见 manifest。脚本先检查已审阅原片 SHA-256，再应用对应帧号；新生成的视频需要重新找剪点。制作工具不随运行包安装。

派生资源为 288×384、24fps、VP9 alpha WebM，无音轨；以透明 PNG 保底。原片含音轨，编码派生物时不带入。按绿色色相抠像和处理边缘溢色，保留与头部暂时分离的呆毛。所有动作使用同一个源画布等比缩小，无逐段拉伸、人物对齐、光流修补或下半身替换。

新“构思”直接使用完整角色原片，已替换旧素材的下半身合成。已知限制：原片尾鳍最右端有少量出画，抠像不补画画外细节；动作回位接近同一坐姿，但并非逐像素相同。

`python scripts/verify-media.py /path/to/evidence` 对十条派生视频完整解码、检查哈希/帧数/透明角落/明显绿像素，并生成每动作十二帧的浅深背景对照图。自动检查不能单独证明水印及人物轮廓合格，仍须检查对照图和实播。

剪点采用实际回位帧，以下源帧区间均为左闭右开：

| 动作 | 源帧 | 源时间（秒） |
| --- | --- | --- |
| 待机 | 0–47 | 0–1.958 |
| 构思 | 47–134 | 1.958–5.583 |
| 写作 | 134–387 | 5.583–16.125 |
| 完成 | 387–439 | 16.125–18.292 |
| 互动 | 439–519 | 18.292–21.625 |
| 等待 | 519–606 | 21.625–25.250 |
| 休息 | 606–720 | 25.250–30.000 |

持续书写采用进入 134–235、循环 235–283、收尾 283–387。两秒循环按头部、手部和书本的接近姿势选取，正向原帧播放，不倒放、不叠影混合；循环接点仍有细微动作差异，自动指标不能证明绝对无缝。播放器沿用动作收尾后切换、写作先收笔的策略。

待机在睁眼回位的第 46 帧停留 3 秒，总循环约 4.958 秒，保留原始眨眼速度。休息在闭眼的第 672 帧额外停留 2.5 秒，总片长 7.25 秒；闭眼和睁眼本身不减速，休息预览的超时同步延长到 8.5 秒。

播放器以两个隐藏视频解码，将已呈现的视频帧绘入同一透明 canvas；循环 seek、加载下一动作时保留最后一帧。媒体层不做透明度渐变，避免两层同时半透明导致人物闪淡。暂停造成的 AbortError 不当成播放失败，过期播放回调不改变当前状态。

重制旧独立素材仍可使用 `python scripts/prepare-media.py /path/to/originals`，会覆盖 assets，执行前应保留当前派生资源。

运行素材内嵌 Client bundle，兼容 Web HTTP 与 Electron file/IPC，两端均不需要额外的 HTTP 素材服务器。只解码当前和切换所需的动画。manifest 记录各文件长度、帧数和 SHA-256；打包检查核验内嵌内容哈希。
