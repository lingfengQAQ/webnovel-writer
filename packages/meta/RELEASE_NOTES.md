# 完整版 8.2.0

- 主插件：`@linfengqaqtat/dsh-scriptor@8.2.0`。
- 嵌入提供方：`@linfengqaqtat/dsh-scriptor-retrieval@8.2.0`。
- 固定宿主：DSH `0.2.0-rc.2`，Node 24.15.0 或 22.19.0 起的 Node 22，pnpm 11.27.1。
- 新增直接编辑、选区改写、行内建议与审读批注的新编辑器，支持逐条采纳/拒绝和请求取消；采纳后仍需保存。
- 增加确定性正文汉字统计及契约章节篇幅核对；世界书条目确认自动补齐模块登记，修复旧书卡在世界构建的问题。
- **旧项目升级后需要补充并确认作品契约的章节篇幅**，保留原有分部内容；未配置仍可使用但不启用范围核对。越界进入原文本规范发现项，不新增审批流程。详见 [升级指南](https://github.com/lingfengQAQ/webnovel-writer/blob/v8/docs/user/upgrade-backup.md)。
- 四包同批为 8.2.0；检索和桌宠仅同步兼容版本，没有新增功能，桌宠不包含在 full 中。
- 嵌入、场景和重排默认关闭。组合包与分别安装主包/提供方二选一，不能重复启用。
- 旧版 preview.6 / 提供方 0.0.8 面向 DSH 0.1.5-rc.2，升级前备份并停止实例；不自动重写旧书或迁移不兼容的旧会话。
