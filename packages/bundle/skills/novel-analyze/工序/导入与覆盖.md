# 导入与覆盖

TXT 先识别 BOM 和严格 UTF-8，无法确定时请作者明确 utf-16le、utf-16be、gb18030 或 big5。编码预检不返回原文示例；不以替换字符继续分析。内部阅读单元身份不同于显示章号，重复目录、卷内章号重置、缺章及无可靠章界均看问题清单，不猜补缺章。

EPUB 按 spine 的实际阅读顺序，目录锚点形成阅读单元；非 linear 内容和脚注定位保留。正文加密、损坏 ZIP、目录越界、DTD、超限和不可解析正文如实报错；字体混淆不等于整本 DRM。只有可读取文字的范围参与分析，图片正文或遗漏资源不称已读。

主聊天预检只有索引与问题。导入建立版本化本地副本，用户原文件只读。重复同一字节与解析设置复用版本；变版、损坏缓存、取消与中断不能清空已验证结果或越过缺口标完成。status 的 covered 按不重叠字符区间计算；allReadableTextCovered 只是可读文字覆盖，fullBookEligible 还要求没有阻塞缺口。实际报告由 build 生成后再交付，不把已有旧报告当当前完成状态。
