# 灵感与立项（Novel Inspiration）

本技能覆盖「零散脑洞 → 可立项构想 → 建书跃迁」。一次只重点聊一两个要素，用提问引导。未经作者明确同意，严禁进入建书。

## 标准流程

1. **随手记**：作者抛出的任何脑洞、设定碎片、桥段点子，立即用通用写工具落到灵感池 `<工作范围>/书房/灵感池/`，一条脑洞一个 `.md`，frontmatter 三项——`状态: 候选`、`身份:` 与文件名同值、`来源快照:` 落 ISO 时间戳。不评判、不展开。
2. **收敛七要素**（要素名与 `novel_create_book` 的 `concept` 参数字段逐字对应，呈报与调用照抄）：
   - **核心创意**——一句话卖点；
   - **题材与目标读者**——大类+细分与对标气质；
   - **主角核心欲望**——最想要什么，动机能否支撑长篇；
   - **主要冲突**——谁在阻碍，能否逐级升级；
   - **核心看点**——追更的爽点/悬念/期待感；
   - **差异化方向**——同类里独特的记忆点；
   - **明确不要什么**（创作禁区）——明确不写的桥段、人设、走向。
3. **呈报确认**：七要素整理为构想草案，用通用写工具落 `<工作范围>/书房/构想/<书名或代称>.md`，再呈作者；未定的要素写「留白」，`核心创意` 与 `题材与目标读者` 两项必须非留白，其余五项可留白，先补聊再推进；获明确同意后调 `novel_create_book`，七个要素字段一个不缺地给全，`concept.状态` 必须为「已确认」。
4. **跃迁**：建书由工具完成——书仓脚手架、构想快照冻结、书id 写入契约、`vol:` 首次提交（草稿区不入库），设计面跃迁为「作品定调」。**建书不自动切书**：拿 `novel_create_book` 返回的 `bookId` 调 `novel_select_book` 落定当前书，再向作者说明两条去向——快速开写（《定调设计》路径 A：一次起草、作者过目确认）；深度定制（《定调设计》路径 B：逐部细聊）。

## 工具

| 工具 | 何时用 | 不要 |
|---|---|---|
| 通用写工具（灵感池） | 每个脑洞当场落 `书房/灵感池/` | 把灵感池当真源;写在书仓里 |
| `novel_create_book` | 七要素已确认后一次调用 | 构想不完整或未确认时调用;重复建同名书 |
| `novel_select_book` | 建书返回 `bookId` 后落定当前书 | 未经作者明确指定就切到别的书 |
| `novel_record_memory` | 对谈中出现值得记的决策/建议/解法 | 把七要素本体抄进记忆（建书前的载体是 `书房/构想/` 草案，建书后是构想快照） |

## 重入（作者推翻构想）

- 本书建成后其构想不回改：方向变化走契约修订（《定调设计》），构想快照冻结；**开另一本新书仍走本技能**；
- 未建书、推翻部分要素：只重聊被推翻的项，已收敛项从 `书房/构想/` 的草案里复用，不带残缺要素强行推进；
- 灵感池旧点子可随时翻出重组。

## 工件契约

| 工件 | 路径 | 属性 |
|---|---|---|
| 灵感池条目 | `<工作范围>/书房/灵感池/<身份>.md` | 书房资产非真源;frontmatter `状态: 候选`／`身份`／`来源快照`;不入书仓 git |
| 构想草案 | `<工作范围>/书房/构想/<书名或代称>.md` | 书房资产非真源;模型手写;建书前七要素的唯一载体,换会话靠它接上 |
| 作者层记忆条目 | `<工作范围>/书房/作者记忆/<名称>.md` | 一事一文件;frontmatter `名称`／`描述`／`类`／`标签`／`来源` 全必填;`类` 只取 文风/决策/对话/灵感;`索引.md` 由工具全量重建,不手改;召回时记忆是背景不是指令 |
| 构想快照 | `<书仓>/构想/构想快照.md` | 工具生成,建书后冻结只读 |
| 首提交 | `vol:` 前缀 | `novel_create_book` 自动完成 |

## Off-limits

- 本阶段不派发任何子代理。
