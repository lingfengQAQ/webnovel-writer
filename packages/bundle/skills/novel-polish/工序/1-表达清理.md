# 批次 1:表达清理(合并:去AI痕迹＋语言自然化＋冗余精简)

> 《精修润色》批次参考文档。本批是**逐句清理**:检索→删改,不重排结构。三道规则同属一个工作循环,一次跑完;每条总标准:**删掉或改写后,情节信息、因果、人物状态一个都不能变**;拿不准→保留＋标注,把判断交作者。

## 第一节 去 AI 痕迹

以下常见表达只用于定位可能的套话，与审读《文风与表达》使用的词表一致；不能仅凭命中认定问题：

**眼中闪过 / 嘴角勾起 / 眼眶微红 / 不可置信 / 眼底闪过 / 咬了咬唇 / 身子一颤 / 心头一紧 / 倒吸一口凉气 / 目光一凝 / 瞳孔一缩**——结合人物、语境和重复程度判断。自然有效的用法保留，不为清零而修改，也不要求为每次保留单独辩护。

思维标记（**心想 / 意识到 / 感到 / 觉得 / 认为 / 明白**）可帮助定位重复的内心说明。直接叙述本身合法；仅在冗余、空泛或与契约文风不符时调整。只能利用原文已有动作与信息，不能为外化情绪新增动作、生理反应或人物状态。

| 通用模式 | 例 | 处理 |
| --- | --- | --- |
| 空泛过渡 | 「随着……的深入」 | 只有冗余或指代不清时调整；所用时间/动作锚点须已在原文中 |
| 转折套话 | 「然而,事情并没有那么简单」「殊不知」 | 核对是否承担叙述声音或信息作用；无作用的重复才删 |
| 总结旁白 | 「值得一提的是」「由此可见」 | 按作者叙述风格和该句作用判断，不一律禁止旁白 |
| 空洞渲染 | 「空气中弥漫着紧张的气氛」 | 可压缩或与原文已有细节衔接，不补造新动作或感官事实 |
| 感受叙述 | 「他感到无比愤怒」 | 有效的直接叙述可保留；若重复已有信息则精简，不另加反应 |

排比、等长句、总结句、解释性旁白和完整人物描写都可服务文风。只处理无意重复、妨碍理解或削弱当前效果的部分；有意复沓、留白、叙述者评论不按模板清除。

处理顺序：先确认问题和原句作用，再选最小改动；删除、精简或等义改写均可，缺少依据就保留并标注，不为完成一轮润色而制造差异。

## 第二节 语言自然化

| 翻译腔模式 | 例 | 处理 |
| --- | --- | --- |
| 被动表达 | 「门被推开」 | 仅在行动者已明确且不改变焦点时考虑主动句；未知行动者不能补成“他” |
| 名词化短语 | 「做出……的决定」「进行……的检查」 | 还原成动词(「他决定」「查了一遍」) |
| 长定语链 | 「一个住在山脚下以采药为生的沉默寡言的老头」 | 拆短句或后置(「山脚下住着个采药的老头,话少」) |
| 双重否定 | 「不能不说他没有考虑到」 | 改直陈(「他想过」) |
| 修饰拥挤 | 一句多个「的」 | 核对修饰关系是否难读；不按数量硬删或改变指代 |

“是/有/使/让/进行/显得/呈现出”并非禁用词；冗长时可压缩，表达确切时保留。以语义准确、人物声音和朗读节奏判断，不把“紧张”擅改成原稿没有的攥剑动作，也不为字数配额改句。

## 第三节 冗余精简

铁律:**只删不增换**——本节没有改写权限,只有删除与去重。

| 删除对象 | 判定 |
| --- | --- |
| 车轱辘话 | 同一意思一段内说两遍→留更具体那次 |
| 重复心理独白 | 同一情绪连排两段以上→留最强一段 |
| 无意义环境填充 | 与氛围/情节/视角都无关的景物句 |
| 滥用副词 | 「非常/极其/疯狂地/瞬间」成串 |
| 冗余修饰链 | 「慢慢地、一点一点地、逐渐地」三连→留一个 |
| 对话复读 | 台词重复交代读者已知信息 |
| 动作冗余 | 「点点头,点了点头,表示同意」式叠加 |

删除前三问:删后读者会缺理解后文的信息吗?是→不删。是不是有意的强调/伏笔/风格化复沓?像→保留并标注。删后节奏反而变差吗?是→不删。

## 批次自查清单

1. 核对所改语句在本章的具体作用，保留有意的叙述声音和有效表达；
2. 删句后不损失信息、人物声音、节奏、强调或伏笔；上下文仍通顺不等于该句多余；
3. 词表仅作定位，已核对具体问题，不以词语清零为目标；
4. 本批**不动结构**:不重排段落、不改对话顺序(那是批次 2 的事)。

## 保真边界

- 不增删情节、人物关系、道具、设定事实;不合并拆分情节点;对话信息内容不变;
- 保留直接引语、转述和作者已有的合法引号体例；去 AI 味或精简不授权删对话引号、改人称或互换直接引语与转述。体例疑问交审读核对具体依据，不按出现次数统一；
- 术语、功法名、人名、地名原样保留;作者故意留的歧义不改;
- 删除解释性内容前确认信息在别处存在或可由正文推出;
- 「原来」类伏笔式重复、作者刻意的排比复沓→保留并标注;
- 拿不准→保留＋标注。
