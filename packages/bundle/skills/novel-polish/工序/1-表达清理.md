# 批次 1:表达清理(合并:去AI痕迹＋语言自然化＋冗余精简)

> 《精修润色》批次参考文档。本批是**逐句清理**:检索→删改,不重排结构。三道规则同属一个工作循环,一次跑完;每条总标准:**删掉或改写后,情节信息、因果、人物状态一个都不能变**;拿不准→保留＋标注,把判断交作者。

## 第一节 去 AI 痕迹

高频 AI 模板禁用词(审读《文风与表达》用同一词表计数,本批负责清除):

**眼中闪过 / 嘴角勾起 / 眼眶微红 / 不可置信 / 眼底闪过 / 咬了咬唇 / 身子一颤 / 心头一紧 / 倒吸一口凉气 / 目光一凝 / 瞳孔一缩**——逐词检索,命中即处理;保留须给出明确理由。

思维标记(**心想 / 意识到 / 感到 / 觉得 / 认为 / 明白**)是降 AI 检测关键指标:直陈内心改外化动作与生理反应;全章保留少量真实必要的「意识到」,堆叠处必改。

| 通用模式 | 例 | 处理 |
| --- | --- | --- |
| 万能过渡句 | 「随着……的深入」 | 删;换成具体时间/动作锚点(「第三遍巡街回来」) |
| 转折套话 | 「然而,事情并没有那么简单」「殊不知」 | 删;让情节自己转折 |
| 总结腔 | 「值得一提的是」「由此可见」 | 删——叙述者跳出来评论就是破功 |
| 空洞渲染 | 「空气中弥漫着紧张的气氛」 | 换成承载情绪的具体动作或感官细节 |
| 感受宣告 | 「他感到无比愤怒」 | 换成体现愤怒的动作(攥紧/耳鸣/太阳穴跳动) |

结构性痕迹:对称三连排比打碎(留最具体的一个);连续等长句式制造参差;段尾总结句删;解释性旁白删;人物出场面面俱到的描写改成只写与情节相关的一两个特征。

处理优先级:**能删则删;删完缺信息则换成具体细节;都不行才重写整句**。

## 第二节 语言自然化

| 翻译腔模式 | 例 | 处理 |
| --- | --- | --- |
| 滥用被动 | 「门被推开」 | 改主动(「他推门」);真正无主语的被动才保留 |
| 名词化短语 | 「做出……的决定」「进行……的检查」 | 还原成动词(「他决定」「查了一遍」) |
| 长定语链 | 「一个住在山脚下以采药为生的沉默寡言的老头」 | 拆短句或后置(「山脚下住着个采药的老头,话少」) |
| 双重否定 | 「不能不说他没有考虑到」 | 改直陈(「他想过」) |
| 「的的不休」 | 一句三个「的」 | 砍到最多一个,靠语序补偿 |

弱动词替换(**是/有/使/让/进行/显得/呈现出**):先找句子真正的动作(他「是」紧张→他攥紧了剑柄);「使/让」字句改兼语句。母语三测:朗读顺口;说给朋友听会怎么说;每句「的」字超两个先砍。

## 第三节 冗余精简

铁律:**只删不增换**——本节没有改写权限,只有删除与去重。

| 删除对象 | 判定 |
| --- | --- |
| 车轱辘话 | 同一意思一段内说两遍→留更具体那次 |
| 重复心理独白 | 同一情绪连排两段以上→留最强一段 |
| 无意义环境填充 | 与氛围/情节/视角都无关的景物句 |
| 滥用副词 | 「非常/极其/疯狂地/瞬间」成串 |
| 冗余修饰链 | 「慢慢地、一点一点地、逐渐地」三连→留一个 |
| 对话复读 | 台词重复交代读者已知信息 |
| 动作冗余 | 「点点头,点了点头,表示同意」式叠加 |

删除前三问:删后读者会缺理解后文的信息吗?是→不删。是不是有意的强调/伏笔/风格化复沓?像→保留并标注。删后节奏反而变差吗?是→不删。

## 批次自查清单

1. 朗读三句:放任何一本小说里都成立?→ 套话,处理;
2. 删句测试:整句删掉上下文仍完整?→ 可删;
3. AI 模板词与思维标记逐词检索无残留(必要保留已标注);
4. 本批**不动结构**:不重排段落、不改对话顺序(那是批次 2 的事)。

## 保真边界

- 不增删情节、人物关系、道具、设定事实;不合并拆分情节点;对话信息内容不变;
- 保留直接引语、转述和作者已有的合法引号体例；去 AI 味或精简不授权删对话引号、改人称或互换直接引语与转述。体例疑问交审读核对具体依据，不按出现次数统一；
- 术语、功法名、人名、地名原样保留;作者故意留的歧义不改;
- 删除解释性内容前确认信息在别处存在或可由正文推出;
- 「原来」类伏笔式重复、作者刻意的排比复沓→保留并标注;
- 拿不准→保留＋标注。
