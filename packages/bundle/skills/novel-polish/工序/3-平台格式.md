# 批次 3:平台格式适配(可选装;永远最后)

> 《精修润色》批次参考文档。**可选装模块**,未装机时跳过。总标准:适配「呈现形式」,绝不触碰「内容文本」。

## 前置

- 平台判定用规则必须**显式声明来源与版本**(哪份平台规范、哪个版本),写进对照说明;声明不了的规则不执行——宁可不做,不可凭印象替平台立法。

## 常见适配项(以声明的规范为准)

| 项 | 做法 |
| --- | --- |
| 段落长度 | 移动端:超长段落按语义切短 |
| 对话排版 | 按作者明确约定和已声明的平台规范处理换段与引号；直接引语与转述可以共存，不按数量自定统一方向 |
| 章节头尾 | 标题格式、章末提示按平台模板 |
| 标点规范 | 全角/半角、省略号(……)、破折号(——)统一为声明的标准 |
| 数字与序号 | 章内编号格式统一 |

## 执行纪律

- 永远排在表达批之后(格式类在表达类后;作者要求倒序给警告不阻断);
- 只动格式与排版,一字一句的内容不变——发现内容问题记审读,不在本批处理;
- 平台敏感词自查属「平台规范检查」模块(可选装,规则同样须声明来源),不在本批展开;
- 适配结果不回写真源与定稿:产物留在草稿区版本链里,定稿以作者批准的版本为准。

## 保真边界

- 不删句、不改写、不合并段落语义;
- 格式调整不改变说话人、人称或叙述方式，不把直接引语改成转述；作者体例与平台要求冲突时列出依据交作者决定，不自行删引号；
- 所有格式决策可追溯:哪条规范、哪个版本、改了哪里;
- 拿不准→保留＋标注。
